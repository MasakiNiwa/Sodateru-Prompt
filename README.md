# 育てるプロンプト

> **プロンプトを育てるシステムノート**

プロンプトを体系的に保管するメモ帳です。
プロンプトの **メモ** と **構造化** と **再利用** を実現するためのブラウザツールで、
プロンプトを育て、差分を残し、部品化し、あとから再利用するための
**ローカルファースト**な知識管理ツールです。

スマートフォン・PC の両方に対応しています。

## 特長

| | |
| --- | --- |
| **時系列でストック** | ひとつの取り組みごとにプロンプトを作り、「版」を重ねて育てます |
| **差分が見える** | 任意の 2 つの版を行単位・語単位で比較できます |
| **構造化して編集** | 見出しを自由に立て、見出しの下に見出しを重ねられます（4 段）。一部だけを更新できます |
| **変数で使い回す** | 本文に `{{変数名}}` と書いておき、出力時に値を差し込めます |
| **部品として再利用** | よく効いたセクションを再利用候補に登録し、別のプロンプトへ挿入できます |
| **すぐ取り出せる** | フォルダ・タグ・全文検索・コマンドパレット（<kbd>Ctrl</kbd>+<kbd>K</kbd>） |
| **テキストで出力** | Markdown / プレーンテキスト / XML タグ / 本文のみ / JSON |
| **まるごとバックアップ** | 全データを 1 つの JSON に書き出し・読み込み |
| **オフラインで動く** | PWA 対応。ホーム画面に追加すればアプリのように起動できます |

## データの扱い

すべてのデータは**利用者のブラウザ内（IndexedDB）にのみ**保存されます。
外部サーバーへ送信されることはありません。

そのぶんブラウザのデータを消去すると失われるため、
**設定 → データ → バックアップを書き出す** を定期的に実行してください。

## 使い方

1. 右下のボタンからプロンプトを作る（ひな形を選べます）
2. 見出しを立てて書く。見出しの下に見出しを重ねられます
3. 試した区切りで「この内容で版を保存」する
4. 差分タブで何が変わったかを確認する
5. 効いたセクションを「部品に」登録して、次のプロンプトで再利用する

詳しくはアプリ内の**ヘルプ**ページを参照してください。

## 開発

ビルド不要の静的サイトです。ネイティブ ES Modules と IndexedDB のみで動作し、
外部ライブラリ・外部フォント・外部アイコンへの依存はありません。

```bash
# 任意の静的サーバーで開くだけ
python3 -m http.server 8765
# → http://localhost:8765/
```

> `file://` で直接開くと ES Modules が CORS で読み込めません。必ず HTTP で配信してください。

### 構成

```
index.html                 アプリシェル（SVG アイコンスプライトを内包）
manifest.webmanifest       PWA マニフェスト
sw.js                      Service Worker（オフライン対応）
assets/css/style.css       Material Design 3 準拠のトークンベース CSS
assets/js/
  main.js                  エントリポイント（初期化・ルーティング）
  core/
    app-info.js            バージョン・リポジトリ URL・更新履歴
    db.js                  IndexedDB ラッパーとスキーマ移行
    store.js               アプリ状態とデータ操作
    models.js              エンティティ定義と正規化
    diff.js                依存ゼロの差分エンジン（LCS）
    outline.js             セクションの階層（見出しの重ね方）
    variables.js           変数プレースホルダ
    templates.js           新規作成時のひな形
    format.js              出力フォーマッタ
    backup.js              バックアップの書き出し・読み込み
    router.js              ハッシュルーター
    theme.js               テーマ適用
    util.js                汎用ユーティリティ
  ui/                      共通 UI 部品（ダイアログ・差分描画・シェル・検索パレット）
  views/                   画面ごとの描画（1 ファイル 1 画面）
docs/SPEC.md               仕様書
```

新しい画面を足すときは `views/` にファイルを 1 つ作り、`main.js` の `route()` に 1 行足します。
DB スキーマを変えるときは `core/db.js` の `MIGRATIONS` に次のバージョンを追記します。

## 公開（GitHub Pages）

`main` ブランチへの push で `.github/workflows/pages.yml` が走り、自動的に公開されます。
初回のみリポジトリの **Settings → Pages → Source** を **GitHub Actions** に設定してください。
